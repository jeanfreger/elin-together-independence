# Elin Together — 「独立」版フォーク

**現在のバージョン：0.26.1069**（zip：`ElinTogether-independence.zip`）。

[English](README.md) | [Français](README_fr.md) | [中文](README_zh.md) | 日本語

[![最新リリース](https://img.shields.io/github/v/release/jeanfreger/elin-together-independence?include_prereleases&label=latest%20release)](https://github.com/jeanfreger/elin-together-independence/releases)

[Elin](https://store.steampowered.com/app/2135150/Elin/) のマルチプレイ MOD、[Elin Together](https://github.com/ElinTogether/ElinTogether) の改造版です。目的はひとつ：**ゲーム内で、ホストと他のプレイヤーの違いをなくすこと**。各自が好きな場所へ、自分の仲間・クエスト・名声・お金とともに行き、ワールド（ストーリー、拠点、ギルド）は共有のままです。ワールドそのものも、特定のプレイヤーの PC に置いておく必要がなくなりました。

元の MOD は、パーティ全員をホストのマップに留め、他のプレイヤーをホストの仲間として扱います。元の作者は、別々のマップを対象外としています。このフォークは、それを試す場所です。MOD 自体の功績はすべて元の作者にあります（[クレジット](#クレジット)を参照）。

> **状態：実験的。** すべてのバージョンはプレリリースで、Elin の Nightly ブランチ向けにビルドされています。大部分はゲーム内の自動テストで確認しています（1 台の PC で 2〜5 個のゲームウィンドウ）。実際に遊んだのは小さなグループひとつだけです：Steam 経由で 2〜3 人、数晩。そのたびに、テストが見逃していたバグが見つかりました。各リリースノートに、実際に遊んだものと遊んでいないものを書いています。先にセーブのバックアップを取ってください：`%USERPROFILE%\AppData\LocalLow\Lafrontier\Elin`

> より詳しい説明（仕組み、正式リリースまでに残っていること）は [English](README.md) または [Français](README_fr.md) 版にあります。

## 変わること

### 誰でも好きな場所へ

- **独立した移動。** プレイヤーはホストなしで別のマップへ行けます。マップとそこでの行動は保存され、離れている間も進行は 1 分ごとに保存され、チャットはマップをまたいで使えます。
- **共有マップ。** 相手がホストでもそうでなくても、他のプレイヤーのマップに合流できます。マップを預かっているプレイヤーが離れると、別のプレイヤーが引き継ぎます。
- **誰も連れ回されない。** ホストがマップを移動しても、他のプレイヤーはその場に残ります。マップには入口から入り、ホストの上へテレポートされることはありません。
- **各自のペースで。** モンスターは、ホストのペースではなく、戦っているプレイヤーが動いたときに動きます。ゲストもホストと同じように滑らかに歩けます。
- **自分の時間は自分のもの。** ベッドに入ったらすぐ眠ります。全員が同時に眠ったときだけ、ワールドの夜が明けます。他のプレイヤーが旅や睡眠をすると日付は進みますが、自分の空腹は増えず、食べ物は腐らず、クエストの期限も動きません。

### プレイヤーごとのもの

- **仲間**は、勧誘したプレイヤー（会話、モンスターボール、騎乗動物、買った動物、どの方法でも）についていき、一緒に移動し、そのプレイヤーの仲間の上限にだけ数えられ、そのプレイヤーの指示に従います。
- **ランダムクエスト、名声、カルマ。** 各自 5 件のクエストと、その報酬。犯罪も同じです：悪事を働いたプレイヤーがカルマを失い、衛兵はそのプレイヤーだけを追います。
- **お金。** 出荷の売上は、出荷箱にアイテムを入れたプレイヤーのものです。ゲストは自分のお金で請求書を払います。
- **自分のキャラクター。** 参加すると、前に遊んでいたキャラクターに質問なしで戻ります。新しいプレイヤーは、ゲームのキャラクター作成画面で自分のキャラクターを作ります。ホストは、ソロのセーブのキャラクターを連れてくることを許可することもできます。
- **自分の設定。** ウィンドウ、自動戦闘、バッグの整理、仲間への指示は、マップを移動しても再接続しても自分のものです。
- **自動戦闘は自分の側を守る。** ゲームの自動戦闘は、それを使ったプレイヤーとその仲間を致命的な一撃から救います（そのプレイヤー自身の戦術スキルとスタミナで）。以前は、ホストの自動戦闘が全員を守り、ゲストの自動戦闘は誰も守りませんでした。誰のものでもない仲間は、誰にも守られません。
- **自分の称号。** 自分で選んだ称号（異名）は自分のものです。ゲストがホストの称号をもらうことはなくなり、セッションをまたいでも自分の称号が残ります。

### 全員でひとつのワールド

- **ストーリー。** ストーリークエストはひとつのログにあり、誰でも開始・進行・完了できます。見たダイアログ、キーアイテム、借金も共有です。
- **拠点。** ゲストもホストと同じように建築できます（床、壁、家具、採掘、掘削、伐採、ゾーン、地形ツール）。一方が建てたものは、すぐにもう一方にも見えます。研究、拠点のスキル、政策、住民、コンテナの設定は、どのプレイヤーでも管理できます。ホストは、チェックボックスひとつで拠点の管理を自分だけにできます。
- **ギルド、好感度、カード図鑑、銀行。** ギルドへの加入はグループ全体に有効で、住民の好感度は全員で同じです。誰かが集めたカードは全員の図鑑に入り、銀行はどこでも同じ中身を表示します。
- **ダンジョンクエスト。** 専用のゾーンを持つクエストは、どのプレイヤーでも受けられます。一人が出発すると、もう一人に同行するかどうかの「はい／いいえ」が表示されます。ゾーンは共有、報酬はクエストを受けた人のものです。
- **マップの音楽。** マップのプレイリストウィンドウで選んだ音楽は、そのマップにいる全員で同じです。
- **プレイヤー同士。** 取引ウィンドウ（双方がアイテムとお金を出し、双方が確定）、誰も死なず何も失わない決闘、そして決闘以外では互いを倒せないこと。

### チーム（任意）

初期状態ではオフです（ホストのチェックボックス *Teams*）。ホストがオンにすると、プレイヤーはチームを作れます。チームごとに自分たちの土地、チェスト、建物、ドアがあり、作った人には土地の権利書が渡され、ホストが許可すればチーム間の PvP もできます。他のチームのチェストは、クラフトにも使えません（ホストも拒否します）。新しいプレイヤーはスポーンゾーンに現れます：ゲーム開始時の草原、ホストのマップ、または名前か番号で指定したゾーン。チェックボックスをオフにすれば、何も変わりません。

### 時間と設定をシンプルに

- **ワールドマップの時間、3 つのモード**（ホストの選択）：*共有時計*（時計はひとつ、ワールドマップは誰も待たない）、*一緒に旅する*（グループがワールドマップを一体で移動し、読み込み中のプレイヤーを待つ）、*個人のペース*（各自のペースで旅し、合流したときに他の人が追いつく）。
- **設定を整理。** 上部にプリセットとわかりやすい選択肢（「おすすめの協力プレイ」「従来のホスト主導」、またはカスタム）、個別のチェックボックスは*詳細設定*にまとめ、各項目の下に説明を表示し、無効な項目はグレーアウトし、「おすすめに戻す」と「元に戻す」を用意しました。フレンドには読み取り専用の「このワールドのルール」が表示されます。同じページはゲーム標準の MOD 設定ページにもあります。

### ワールドが全プレイヤーを見る

- **ワールドの内容はホストだけでなく全プレイヤーが基準。** 街の掲示板（名声の条件、危険度、報酬）、店の在庫と特別な棚、マップのスポーン、樽、熟成棚、母乳は、ホストのキャラクターだけでなくマップ上のプレイヤーに従います。
- **拠点と街の暮らしを全プレイヤーに。** 襲撃、幸運の月、プレイヤーと過ごした日数、農場の雨は全プレイヤーを数え、住民・僧侶・ネフィアのボス・噂・石投げは各プレイヤーとそのカルマを基準にします。ボス撃破で到達階層がマップ上の全員に記録され、召喚物は自分の主人に従います。
- **各プレイヤーの運勢・日記・カウンター**（運勢のロール、再構築レベル、日記、秘蔵品、既知のレシピ、スケッチ、曲、復活地点）はそのプレイヤーのもので、ワールドのコピーをまたいで保たれます。仲間の勧誘費用は一度だけ支払われます。
- **プレイヤーごとの自動戦闘**、戦闘ルールの統一（弱点、召喚物の下限、投擲の成長、速度）、ゲーム標準ルールの決闘。
- **難易度はプレイヤーに従う。** クエストの難易度は、クエストを受けたプレイヤーに従います。

### ゲストもソロのプレイヤーと同じように遊べる

ホストにできることがゲストにもできるようにする、数十の修正：死亡と遺言、神の贈り物、祭壇、罠、魔法書、治療師、祝福、出資、ルーン、自動収納、手に持った道具、Kettle でのコピー依頼、バーテンダーでの仲間の蘇生、ホストの画面に開いてしまっていたウィンドウ、係留柱、ゲストの仲間が罠にゲストの拾い集めの特技を使うこと、クエストを終えたゲストのそばに立つストーリーの住民、ゲストにも読める「一日が終わる」、ゲストの「常に整頓」でゲームが固まる問題、マップを離れている間に抜けたゲストが接続切れと見なされなくなったこと…。また、各ゲストのストーリーシーン、バッカーのリスト、Churyu の数は、ワールドのコピーをまたいで各自のものとして保たれます。完全な一覧は開発者のメモに保管されていて、公開していません。

### ワールドはホストの PC に依存しない

- **デポがワールドを保管します**：プライベートな GitHub リポジトリ、共有フォルダ、または小さなサーバーアプリ。最初に来たプレイヤーがワールドを取り出してホストし、セーブのたびにデポへ戻り、そのプレイヤーが抜けたら次の人が引き継げます。[デポ](#デポでワールドをオンラインに保つ)を参照。
- **持ち主が変わるワールド。** ワールドを引き継いだ人は自分のキャラクターで遊びます。前のホストは、参加するときに自分のキャラクターに戻ります。すでに誰かがホストしている場合は、コピーを開く代わりにそのゲームへ案内されます。
- **ホストは何もしなくてよい。** 他のプレイヤーがいる間、ワールドは 2 分ごとに自動保存されます。すでに共有されているワールドは、読み込むとすぐ Steam フレンドに公開されます。
- **接続が切れても大丈夫。** 接続を失ったゲストは、自動でゲームに戻ります（3 分間再試行）。
- **ゲーム同士の食い違いを防ぐ。** 回線が詰まってもメッセージを捨てません。2 秒ごとにマップごとの数値を比べ、食い違いが続くマップはその場で読み込み直します。
- **より安全なネットワークデータ**（元の MOD から取り入れ）。他のゲームから送られてくるものは、ゲームとその MOD 自身のデータの種類としてしか読み込まれず、それ以外は拒否されます。
- **専用サーバー。** Minecraft のサーバーのように、誰も操作しない Elin がワールドを動かし続けます。

### 全員が同じ MOD を、サブスクライブなしで

- **ゲームの MOD は自動で取得されます。** 参加するときにワークショップの MOD が足りなければ、サブスクライブせずにダウンロードされ、Elin がそのゲームの MOD で一度だけ再起動して、ゲームに戻してくれます。次に起動したときは、自分の MOD リストに戻ります。[MOD](#mod) を参照。
- **Elin のバージョンが違っても一緒に遊べます。** 全員で同じでなければならないのは MOD のバージョンだけです。Elin のバージョンが違うプレイヤーは、警告のうえ参加できます。

これらのほとんどは**ホスト側のチェックボックスまたは選択肢**です。チェックを外すと、MOD は元の動作に戻ります。[ホストの設定](#ホストの設定)を参照。

## インストール

Steam の Elin を **Nightly** ブランチ（Steam → Elin を右クリック → プロパティ → ベータ）にして、[YK Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=3400020753) を入れてください。ワークショップで [Elin Together](https://steamcommunity.com/sharedfiles/filedetails/?id=3773298709) をサブスクライブすると、一緒に入ります。サブスクライブ後に Elin を一度起動して、閉じてください。

1. [Releases ページ](https://github.com/jeanfreger/elin-together-independence/releases)から `ElinTogether-independence.zip` をダウンロードします。
2. フォルダごと解凍して `Install.bat` を実行します。Elin を探して MOD をコピーし、ワークショップ版からこの版に切り替えます。
3. Steam から Elin を起動します。

`Uninstall.bat` でワークショップ版に戻せます。何も削除されません。zip には `Install.bat`、`Uninstall.bat`、`Server.bat`、`README.txt` が入っています。インストーラーと説明は英語です（説明には中国語もあります）。現在は Windows 版 zip のみ提供しています。手順は各リリースのページにもあります。

**全員が同じリリースをインストールしてください。** このフォークはワークショップ版とは接続できず、このフォークの別のバージョンとも接続できません。各リリースは Elin の特定のバージョン向けにビルドされていて、リリースのタイトルに書いてあります。

## 遊び方

タイトル画面の *Elin Together* ボタン、またはゲーム中に Esc → Mods → Elin Together で MOD のパネルを開きます。タブは「ロビー」「サーバー設定」（ホストのルール）「クライアント設定」で、セッションが始まると「セッション情報」が加わります。

- **ホストする。** 土地を確保済みのセーブを読み込み、「ロビー」タブで「サーバー起動」を押します。すでに共有されているワールドは、自動で Steam フレンドに公開されます。
- **参加する。** Steam の招待を受けるか、Steam のフレンドリストでフレンドの名前から「ゲームに参加」を選ぶか、「ロビー」タブでゲームを選びます。「アドレスで参加」はサーバー用です。
- **ルール。** ホストが「サーバー設定」で決めます。変更はすぐに全員に適用されます。

## デポでワールドをオンラインに保つ

デポは、共有ワールドを特定のプレイヤーのセーブの外に保管します。これで、グループは誰か一人がいることに頼らなくて済みます。ホストする可能性のあるプレイヤーは、「クライアント設定」で一度だけ設定します：**デポ**と、パスワードやキーがある場合は**デポのキー**。参加するだけのフレンドには、どちらも必要ありません。

| デポ | 必要なもの | 「デポ」の設定 |
|---|---|---|
| プライベートな GitHub リポジトリ | グループの誰か一人の GitHub アカウント。つけっぱなしの PC も、ポート開放も不要。 | `github:所有者/リポジトリ` |
| Elin Together Server（zip の中の `ElinTogetherServer.exe`） | つけっぱなしの PC。Elin のインストールは不要。TCP ポート 55557。 | `アドレス:55557`、または「アドレスで参加」だけ |
| 共有フォルダ | 全員がアクセスできるフォルダ（共有または同期）。 | フォルダのパス |

そのあと、「ロビー」タブで：

- **このセーブをサーバーに置く**（セーブを読み込み済みで、まだ他のプレイヤーに公開していないとき）：そのセーブがデポのワールドになります。
- **サーバーから世界を取り出してホストする**（タイトル画面から）：最新のワールドを受け取ってホストし、他のプレイヤーは Steam で参加します。すでに誰かがホストしている場合、ボタンにその名前が表示され、そのゲームに参加できます。
- セーブのたびにデポへ戻ります（多くても 5 分に 1 回、終了時にもう 1 回）。ホストが抜けたら、誰でもワールドを取り出せます。ホストがクラッシュした場合、ワールドは 3 分後に自動で解放されます。

**GitHub を使う場合**、リポジトリの所有者が：

1. github.com で、このワールド専用の空の**プライベート**リポジトリを作ります（MOD は公開リポジトリを拒否します）。
2. そのリポジトリだけに限定したアクセストークン（fine-grained token）を作り、権限を *Contents: Read and write* にします。
3. **デポ**に `github:所有者/リポジトリ` と書き、**デポのキー**にトークンを貼り付けます。
4. この 2 つを、ホストする可能性のあるフレンドに伝えます。フレンドに GitHub アカウントは不要です。

キーは、各 PC の MOD の設定ファイルに平文で保存されます。開けるのはそのリポジトリだけで、ワンクリックで無効にできます。zip で 20 MB を超えるワールドは拒否されます。GitHub はワールドのすべてのバージョンを残します。これは無料のバックアップになりますが、セーブのたびにリポジトリが大きくなるということでもあります。大きくなったら、削除して新しく作り直してください。デポには、ワールドの MOD リスト `modlist.txt` も保管されます。

**専用サーバー。** `ElinTogetherServer.exe` には 2 つ目のモード「With Elin on this PC: the world runs all the time」があります。Elin がウィンドウなしで裏で動き、プレイヤーは「アドレスで参加」（`アドレス:55556`、UDP）を使います。`Server.bat` は、ゲームウィンドウ付きで同じことをします。Windows のみ。

## MOD

ゲームに参加するとき、またはデポからワールドを取り出すときに、ワークショップの MOD が足りない場合：Steam アカウントは何もサブスクライブしないまま MOD がダウンロードされ、Elin が閉じて、そのゲームの MOD で**一度だけ**再起動し、ゲームに戻してくれます。自分の余分な MOD が参加を妨げている場合は、それらなしで一度再起動します。次に Elin を起動したときは、自分の MOD リストがそのまま戻ります。何かが削除されたり、サブスクライブ解除されたりすることはありません。

- 基準になるリスト：ワールドがデポから来た場合はデポの `modlist.txt`、そうでなければホストの MOD。
- Elin が自動で再起動しない場合は、30 分以内に手動で起動してください。ゲームに戻してくれます。
- 手動で入れた MOD（ワークショップ外）はダウンロードできません。その名前が表示されます。
- 自分の MOD を保ったまま、違いだけ知らせてほしい場合：「クライアント設定」で「ゲームのModを自動で取得する」のチェックを外します。

**これらの MOD はホストが選び、そのコードはあなたの PC で動きます。信頼できる相手とだけ使ってください。**

AutoAct と Dynamic Riding に対応しています。その他の MOD の互換性は、元の MOD と同じです。

## ホストの設定

Esc → Mods → Elin Together →「サーバー設定」。新しい挙動にはそれぞれチェックボックスがあり、ゲーム内に一行の説明があります。ルールはホストのもので、変更するとすぐに全員に適用されます。

## 既知の制限

- **実際に遊んだのは小さなグループひとつだけです。** 最近の変更の多くは、テスト環境でしか動かしていません。リリースノートやコミットメッセージの「未プレイ」は、文字どおりの意味です。
- **ホストが抜けたりクラッシュしたりしても、ゲストが自動でワールドを引き継ぐことはありません。** 誰かが手動でデポから取り出します。
- **ワールドの日付はひとつ**です。ワールドマップの旅が日付をどう進めるかは、ホストが選ぶ*ワールドマップの時間*のモードによります。空腹、腐敗、期限などの影響はプレイヤーごとです。
- 自分だけの夜の数秒間、プレイヤーは攻撃されることがあります。他のプレイヤーにとってワールドは動き続けています。
- ホストとゲストがマップで再び合流すると、ゲストの画面が読み込み直されます。チェックボックス「ホストと合流してもワールドを読み込み直さない」で避けられますが、新機能のため初期状態はオフです。
- ホストの画面では、歩いているゲストが 3 マスずつ飛ぶように動くことがあります。
- マップを預かっているプレイヤーに拒否されたプレイヤーにも、ワールド全体が送られてしまいます。
- **4 人以上**：1 台の PC で 5 つのゲームウィンドウをテストしましたが、本物の PC 5 台では試していません。人数が増えると、ゲームが重くなる可能性があります。
- 二人でのダンジョンクエストで、ゲストがクエストを受けた場合：「討伐」・収穫・音楽のクエストに対応します。防衛クエストは一人でこなします。
- 決闘には、アリーナ、賭け、降参ボタンがまだありません。装備中のアイテムは取引できません。
- MOD の自動取得：ワークショップの MOD のみ。Steam による Elin の再起動、Steam ロビー経由の復帰、Steam Deck や Linux、Mac では、まだ試していません。
- まだ再現できていません：issue 5 から、訓練用のかかしに向けた杖。issue 6 から、見えないインベントリのスロットで失われるアイテム。
- まれな競合がいくつか知られていて、未修正です：二人が同じマスに建築する、旅のあとに騎乗動物が二重になる。

完全な一覧は開発者のメモに保管されていて、公開していません。

## 問題が起きたら

- ホストが関係するチェックボックスを外します。その点について、MOD は元の動作に戻ります。
- 他のプレイヤーと食い違ったプレイヤーは、コンソールで `emp.reconnect_self` と入力します。
- [このリポジトリの issues](https://github.com/jeanfreger/elin-together-independence/issues) に、各プレイヤーの `Player.log` と `ElinMP/Logs/Session_<日付>.log`（`%USERPROFILE%\AppData\LocalLow\Lafrontier\Elin` にあります）を添えて報告してください。このフォークの問題を、元のプロジェクトには報告しないでください。

## ビルド

MOD は `dotnet build ./ElinTogether -c ReleaseNightly` でビルドします。ゲームがインストールされている必要があります。環境変数 `ElinGamePath` にゲームのフォルダを指定してください。`SteamContentPath`（`steamapps/workshop/content`）は `YKFramework.dll` 用です。.NET SDK 11.0 プレビュー、`global.json` を参照。

```ps
git clone https://github.com/jeanfreger/elin-together-independence
cd elin-together-independence
dotnet restore ./ElinTogether --locked-mode
dotnet build ./ElinTogether -c ReleaseNightly
```

リリース用のパッケージ作成とテストツールはリポジトリに置いていません。テスト環境も公開していません。

## 仕組み（簡単に）

元の設計：ホストがワールドをシミュレートし、変化はすべて差分としてクライアントに送られ、クライアントは自分の操作をホストに送ります。このフォークは**ゾーンのリース**を加えました。ホストのマップを離れるプレイヤーは、行き先のマップのリースをホストに求め、自分のワールドのコピーを読み込んで、そのマップを自分でシミュレートします。戻るときと定期的なチェックポイントで、マップをホストに送り返します。基準はホストのままです。リースを持つプレイヤーは、そのマップを他のプレイヤーのためにホストでき、離れるときに引き渡します。

デポは、ひとつのアーカイブにまとめたワールドと、誰がホストしているかを示すロックです。ホストは 1 分ごとにロックを更新し、3 分間更新されなかったロックは空きとみなされます。
